# efood — Parte 1

Home (lista de restaurantes) e Perfil (cardápio) do projeto efood, feitos com React, React Router DOM e Styled Components, seguindo o layout do Figma. Os dados vêm da API `https://api-ebac.vercel.app/api/efood/restaurantes`.

## Rotas

- `/` Home
- `/restaurantes/:id` Perfil do restaurante

## Como rodar

```bash
npm install
npm run dev
npm run build
```
